## Overview
This repository houses my completed Week 1 frontend engineering tasks for the WeIntern Internship Program. Each module focuses on writing clean, semantic HTML5 markup paired with responsive CSS3 layout systems and interactive UI states.

---

## Completed Modules

### Module 1: Developer Portfolio (`Portfolio/`)
* A multi-page personal website consisting of **Home**, **About**, **Projects**, and **Contact** views.
* Features a responsive navigation header, reusable CSS custom properties, experience timeline cards, and a validated contact form.

### Module 2: Business Landing Page (`business-landingpage/`)
* A responsive single-page website built for **The Savory Bistro**.
* Showcases a sticky top navigation bar, hero banner with dual call-to-action buttons, a 4-column offerings grid, and an interactive reservation form.

### Module 3: CSS Layout & Animation Exercises (`Css-challenge/`)
* Practical frontend layout demonstrations covering:
  * **Flexbox Layout:** A 3-card horizontal row that adapts cleanly to vertical stacking on mobile screens.
  * **CSS Grid System:** A 6-card responsive dashboard built using `repeat()` and `auto-fit`.
  * **Motion & Transitions:** Subtle hover states and a `@keyframes` loading indicator.
